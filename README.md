# 📬 올댓메시지 웹판

쿨메신저(.xls)와 카카오톡 대화 내보내기(.txt)로 받은 학교 메시지에서 **일정·마감을 찾아 한곳에 정리**해 주는 초등 교사용 도우미예요.
기본판(규칙) → AI판(Gemini 검토·보정) → **웹판(웹 주소 + 구글 로그인 + 클라우드)** 으로 발전시켰어요.

> 🎬 **데모 보기:** `app.html?demo=1` — 꾸며 낸 예시 데이터만 보여 주고, 아무것도 저장하거나 보내지 않아요.

## 3가지 판

| | ⚙ 기본판 | 🤖 AI판 | ☁️ 웹판 |
|---|---|---|---|
| 정리 방식 | 규칙 | 규칙 + Gemini 검토·보정 | 규칙 + Gemini 검토·보정 |
| 여는 방법 | PC의 파일 | PC의 파일 | 웹 주소 + 구글 로그인 |
| 저장 위치 | 내 PC 브라우저 | 내 PC 브라우저 | 브라우저 + N 드라이브 + Firestore(일정·요약만) |
| 여러 기기 | ✕ | ✕ | ○ (학교 PC·휴대폰) |

## 주요 기능

- 📥 쿨메신저 저장 폴더·카톡 내보내기 폴더 연결 → 새 메시지 자동 읽기
- 📅 일정표·달력·할 일·마감, 📬 알림판, 🔗 링크 모음, 📷 사진 표시
- 🤖 Gemini 다듬기: 달력표로 날짜 확인, 미정·변경·취소 구분, 근거 문장 재검사, 갈린 것만 Pro 재확인, 🎯 정확도 점검
- 🔑 구글 로그인 → Firestore에 **일정·요약만** 동기화 (휴대폰에서도 같은 일정)
- 🗂 N 드라이브(학교 네트워크 드라이브) 폴더에 저장 → 학교 PC끼리 이어서 쓰기
- 🎬 발표용 데모 모드

## 개인정보 원칙

- 클라우드(Firestore)에는 날짜·시간·제목·한 줄 요약·장소·분류·마감·완료·할 일만 올려요.
- **메시지 원문·보낸 사람·학생 이름·전화번호는 올리지 않아요.** 올리기 전에 이름·전화번호 꼴은 `○○○`로 가려요.
- 보안 규칙(`firestore.rules`)이 **로그인한 본인만** 읽고 쓰게 하고, 정해진 칸·길이만 받아요.
- Gemini 키는 코드에 없어요. 쓰는 사람이 각자 브라우저에서 넣어요.
- `firebase-config.js`의 값은 Firebase 웹 앱의 공개 설정값이에요(비밀 키 아님).

## 폴더 구성

```
public/
  index.html          시작 페이지 (탭 3개: 기본판 · AI판 · 웹판)
  app.html            웹판 앱 (AI판 v2.5에서 출발) · ?demo=1 → 데모 모드
  cloud.js            구글 로그인 + Firestore 동기화
  firebase-config.js  Firebase 웹 앱 설정값 (공개 값)
firebase.json         Hosting · Firestore 설정
firestore.rules       보안 규칙
```

## 실행 · 배포

- 내 PC에서 보기: `public` 폴더를 간단한 웹 서버로 열어요. (예: `python -m http.server 5173 --directory public`)
- 배포: `firebase deploy --only hosting,firestore:rules`
