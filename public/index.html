⚙ 기본판 — 내 PC 안에서만

쿨메신저 저장 파일(.xls)과 카톡 대화 내보내기(.txt)를 넣으면, 규칙으로 날짜·마감·장소를 찾아 일정표·달력으로 정리해요. 메시지는 밖으로 나가지 않아요.

  • 📥
    메시지 넣기파일을 끌어다 놓거나 폴더를 연결하면 새 메시지를 자동으로 읽어요.
  • 📅
    일정표 · 달력 · 할 일오늘·이번 주·급한 마감, 월/주 달력, 끌어서 날짜 옮기기, 주간·월간 인쇄
  • 📬
    알림판작은 창에 급한 것·오늘·다음 일정까지 남은 시간 · 컴퓨터를 켜면 자동으로
  • 🔗
    링크 · 📷 사진 표시메시지 속 링크 모음, 사진이 함께 온 메시지 표시
🐙 GitHub 저장소
기본판은 웹 주소가 아니라 PC의 파일로 써요.
  1. PC에 둔 「올댓메시지.html」 파일을 크롬으로 열어요.
  2. + 메시지 넣기로 쿨메신저 저장 폴더나 카톡 내보내기 파일을 연결해요.
  3. 일정은 그 PC의 브라우저에만 저장돼요.

🤖 AI판 — 기본판 + Gemini 다듬기

기본판이 먼저 정리한 결과를 Gemini가 원문과 비교해 검토·보정하고, 앱이 두 결과를 합쳐요. 날짜가 다르면 선생님이 골라요.

  • 📆
    달력표로 날짜 확인「다음 주 목요일」「22일(화)」을 달력표에서 골라 요일 실수를 줄여요.
  • 🧭
    확정 · 미정 · 변경 · 취소 · 지난 일「10일 혹은 17일」은 후보로, 「26일로 연기」는 날짜 변경으로 알려 줘요.
  • 🔍
    앱이 다시 검사근거 문장이 원문에 있는지, 요일이 맞는지 확인 · 지어낸 일정은 버려요.
  • 🔁
    갈린 것만 Pro로 재확인 · 선생님 선택으로 배우기고른 결과를 다음 질문의 예시로 보내요.
  • 🎯
    정확도 점검예문 20개로 기존·Gemini·합친 결과 점수를 비교해요.
AI판도 PC의 파일로 써요.
  1. PC에 둔 「올댓메시지_AI판.html」 파일을 크롬으로 열어요. 파일 이름에 「AI판」이 있어야 Gemini 기능이 켜져요.
  2. 설정에서 내 Gemini 키를 넣어요. 키는 그 PC에만 저장돼요.
  3. 메시지를 넣으면 기본판 정리 → Gemini 검토 → 합치기 순서로 정리돼요.

🔐 Gemini 키는 이 PC에만 저장하고, 보낼 때 학생·학부모 이름과 전화번호를 ○○○로 가려요.

☁️ 웹판 — AI판 + 웹 주소 + Firebase

웹 주소로 어디서나 열고, 구글 로그인한 본인만 볼 수 있어요. 클라우드에는 일정·요약만 저장하고, 메시지 원문은 올리지 않아요.

  • 🌐
    Firebase Hosting 주소설치 없이 크롬에서 바로 열어요. (주소는 배포한 뒤 정해져요)
  • 🔑
    구글 로그인 (Firebase Authentication)로그인한 본인 일정만 읽고 쓸 수 있게 보안 규칙을 걸어요.
  • 🗂
    Firestore에 일정·요약만학교 메시지 원문은 PC에만 · 휴대폰·학교 PC에서 같은 일정 보기
  • 🐙
    GitHub에 코드 공개해커톤 제출용 저장소 · 키·개인정보는 코드에 넣지 않아요.
  • 🎬
    데모 모드발표 때는 꾸며 낸 예시 데이터로만 보여 줘요.
